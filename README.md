# Zombie Outbreak V1

A standalone 1–4 player cooperative zombie survival/extraction Discord game.

Core systems: survivor classes, infected types, finite city loot, noise/hordes, day/night, hunger/water, infection, backpack management, weapon rarity/ammo, crafting, barricades, missions, revives, extraction, persistent profiles, and difficulty modes.

## Wispbyte
Set `JS_FILE=src/index.js`, `DISCORD_TOKEN`, `DISCORD_CLIENT_ID`, and `DISCORD_GUILD_ID`.
Use Node 22 LTS if available.
